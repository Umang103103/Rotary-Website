# Image Placeholder Guide

Since this project uses placeholder image references, you have two options:

## Option 1: Use Online Placeholders (Temporary)

The components are set up to gracefully handle missing images. You can use online placeholder services or leave them as-is for development.

## Image Guidelines

- Use high-quality images (at least 1200px width for hero/featured)
- Optimize images before adding (use tools like TinyPNG)
- Preferred formats: PNG for graphics/photos with transparency, JPG for photos
- Keep file sizes reasonable (under 500KB per image when possible)
- Use descriptive, consistent naming

## Quick Image Creation

If you need quick placeholder images with proper dimensions:

1. Use Canva (free) to create branded images
2. Use Photoshop or GIMP for photo editing
3. Use online tools like Placeholder.com or Lorem Picsum for temporary placeholders

The site will work without images, but adding real photos will significantly improve the visual appeal!
